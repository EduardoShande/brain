Become an automation engineer.

The job: turn repetitive, multi-system work into reliable automated systems, and increasingly, wire in AI agents to handle the judgment steps. This is the path, what to learn, what the work actually looks like, and where to learn it.

Level
01 · The role

What an automation engineer actually does

Not a job title you apply for so much as a capability you sell. You find work that humans repeat, and you replace it with a system that runs itself, then you keep it alive and prove it saved money.

01

Map the work. Sit with a process, find the repetitive, rule-based steps that eat hours, and decide what is worth automating.

02

Wire the systems together. Connect apps and APIs so data flows without a human copy-pasting: forms, CRMs, databases, spreadsheets, email, Slack.

03

Add judgment with AI. Where a step needs reading, deciding, or drafting, call an LLM or an agent instead of a person, the premium tier of the work today.

04

Make it reliable. Handle errors, retries and edge cases; monitor it; get alerted when it breaks. This is what separates a $500 toy from a $2K/mo system.

05

Prove the value. Document it, hand it off, and quantify hours saved × cost. That number is what gets you paid and renewed.

03 · Reference

Skill map

The roadmap is the order. This is the map by capability, the six areas and the one thing to actually master in each. Click any card to open it.

AProgramming

The escape hatch for anything a no-code tool can't do. You won't write huge apps, you'll write the 20 lines of Python that a workflow calls when it hits something custom.

Master: Python + reading API docs
BAPIs & data

Every automation is really moving data between systems. Auth, pagination and rate limits are where beginners get stuck; a database is where the data lands.

Master: REST auth + one SQL database
COrchestration

The workflow tools that let you ship in hours, not weeks. n8n is the technical, self-hostable one with the best margins; Zapier/Make win on speed and client familiarity.

Master: n8n, deeply
DAI & agents

The difference between "moves data" and "decides and acts." Start with single reliable LLM calls, then tool-calling, then multi-step agents with memory and evals.

Master: reliable structured output, then one agent framework
EReliability

Anyone can build a flow that works once. Getting paid means it works at 3am, recovers from a failed API, and tells you when it can't.

Master: Docker hosting + error handling
FBusiness

The skill most engineers skip and most agencies live on. Finding the right process, pricing it, and proving the ROI is worth more than any single tool.

Master: ROI framing + scoping

What you actually build at work

Real automations engineers ship, in the trigger → steps → tools shape you'll use for every job. Each one below is a sellable offer.

Employee onboarding
on HR marks a candidate hired
→ generate offer letter for e-sign
→ open an IT ticket to create accounts
→ add to payroll & schedule day-1 check-in

form · DocuSign · Jira · Slack · n8n

Scheduled reporting
every Monday 08:00
→ pull sales from CRM + database
→ format, chart, summarize
→ post to Slack & email the team

Postgres · n8n · Slack

Saves hours every month and the report never gets forgotten.

Lead capture & enrichment
on website form submit (webhook)
→ enrich company data via API
→ dedupe & create CRM record
→ alert the right rep in Slack

webhook · enrichment API · HubSpot · Slack

Leads answered in minutes, not the next business day.

Content repurposing AI
on new blog post (RSS)
→ store in Airtable
→ LLM drafts a LinkedIn post + tweet thread
→ queue drafts for human review

RSS · Airtable · Claude · n8n

One post becomes five, with a person only approving.

Invoice & expense intake AI
on invoice email attachment
→ LLM extracts vendor, amount, dates
→ validate against rules
→ push to accounting, flag exceptions

Gmail · LLM · QuickBooks

Support triage agent AGENT
on new support ticket
→ agent classifies & sets priority
→ drafts a reply using RAG over your docs
→ auto-answers simple ones, routes the rest

Zendesk · vector DB · LangGraph

Faster first response and agents focus on hard tickets.
